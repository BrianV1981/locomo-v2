# LoCoMo V2 Datasets Vault

This directory contains the purified, 100% solvable **1,923-question** LoCoMo V2 benchmark datasets. 

All datasets in this folder share the same base structure:
- 63 unanswerable questions have been permanently deleted.
- 99 `locomo-audit` logic errors have been mathematically verified and fixed.
- 22 character names and 5 entities have been decontaminated to prevent LLM memorization.
- Bloat tags (`blip_caption`, `query`, `evidence`) have been stripped to enforce End-to-End evaluation.

There are **6 variants** of the dataset available, split into two distinct categories depending on your agent's evaluation pipeline:

---

## Category 1: The Multimodal URL Datasets
Use these datasets if your agent has active vision capabilities and expects to be fed raw image files during the chat simulation. These datasets retain the `"img_url"` key in the dialogue turns.

1. **`locomo_v2_base.json` (Live URLs)**
   * Retains the original live internet URLs. Warning: vulnerable to future link rot or 404/403 errors depending on the host server.
2. **`locomo_v2_web.json` (GitHub Raw)**
   * Highly recommended for cloud-based evaluations. All 834 live image URLs have been swapped to point to the permanent `raw.githubusercontent.com` preservation vault.
3. **`locomo_v2_local.json` (Air-Gapped)**
   * Highly recommended for offline/local GPU evaluations. All 834 image URLs have been swapped to relative paths (e.g., `../images/<hash>.jpg`), allowing runners to seamlessly load images from local disk.

---

## Category 2: The Text-Flattened OCR Datasets
Use these datasets if your agent is a pure-text LLM (or if you want to save thousands of context-window tokens). 

In these datasets, the `"img_url"` key has been **completely deleted** to prevent token bloat. Instead, the high-fidelity OCR description of the image has been injected as a clean sibling key (e.g., `"minicpm_caption": "This image shows..."`). Your runner script can dynamically pull this text to simulate visual understanding.

4. **`locomo_v2_minicpm.json` (100% Complete)**
   * Contains 834/834 image captions generated by `minicpm-v:latest`. *Considered the Gold Standard for OCR accuracy.*
5. **`locomo_v2_moondream.json` (100% Complete)**
   * Contains 834/834 image captions generated by the lightning-fast `moondream:latest`.
6. **`locomo_v2_qwen.json` (100% Complete)**
   * Contains 834/834 image captions generated by `qwen2.5vl:3b`.

---
*Note: The legacy LLaVA and BLIP datasets were deliberately purged due to hardware deadlocks and extreme OCR hallucinations.*
