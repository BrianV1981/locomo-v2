# Data Directory

This directory contains the core datasets and source files for the LoCoMo V2 benchmark.

To keep the root of this folder clean, all intermediary files and legacy backups have been neatly organized into subdirectories.

## 📂 Active Datasets (The Golden Variants)
These 4 files sit in the root of the `data/` directory and are the final, mathematically verified datasets ready for evaluation. They contain all corrections, decontaminated names/entities, and the 82 contextually anchored replacement questions.
*   **`locomo_v2_web.json`**: The absolute golden source. Images point to the raw GitHub cache.
*   **`locomo_v2_local.json`**: Images point to air-gapped local relative paths.
*   **`locomo_v2_llava.json`**: Text-only variant pre-baked with rich LLaVA OCR descriptions (`llava_caption`).
*   **`locomo_v2_minicpm.json`**: High-fidelity variant pre-baked with MiniCPM OCR descriptions. (Used by the A.I.M. search engine).

---

## 📂 `source/` (Intermediary & Original Files)
This folder contains all of the structural building blocks used by the `scripts/` pipeline to assemble the final variants. 
*   **`locomo10.json`**: The original V1 dataset downloaded from Snap Research.
*   **`errors.json`**: The 156 forensic text corrections identified during the live-agent audit.
*   **`replacement_manifest.json`**: The strict mapping file used to replace dead image links with active unused images.
*   **`regeneration_context.json`**: The conversational context used to ground the LLM when writing new questions.
*   **`regenerated_questions.json`**: The output file containing the 82 contextually anchored V2 questions.
*   **`salvaged_82_questions.json`**: Legacy scrap file.

## 📂 `backups/`
Contains automatic timestamps generated by the `rebuild_all_datasets.py` script whenever a dataset compilation is run, preventing accidental data loss during large operations.
